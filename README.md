# ZombieShooter-Python
A classic 2D shooting game built in Python using the Pygame module - My first Game Development Project

Features of the Game - 
1. Tracks score based on number of time you hit the Zombie.
2. Zombie Respawns as soon as they dies.
3. The player respawns in the middle if they take 100 Hits.
4. custom sound effect on hitting the Zombie, player death and shooting bullets.

Controls -
1. **left, Right** Arrow keys to **Move**.
2. **up** Arrow key to **Jump**.
3. **Space** to **Shoot**.

Prerequisites -
1. Python installed on your computer.
2. pygame module installed

Procedure to install pygame- 
1. go to command prompt.
2. ensure python is added to path.
3. Enter - pip install pygame
